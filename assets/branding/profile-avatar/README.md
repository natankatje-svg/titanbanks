# TitanBanks — Profile Avatar

## Doel
Premium social media profielfoto voor TitanBanks op Instagram, TikTok en LinkedIn.

## Primary Reference
`assets/branding/logo-white.png` — wordmark met bliksem + gloeilamp icoon

## Stijl
Dark luxury tech — Apple × DJI × Nothing inspired.
Diepzwart of deep navy achtergrond, hoog contrast, subtiele elektrische glow.
Geen felle kleuren. Geen drukke achtergronden. Minimal, premium, instant herkenbaar.

## Output Use
- Instagram (110×110px weergave, upload 320×320px minimum)
- TikTok (200×200px weergave)
- LinkedIn (400×400px aanbevolen)

Exporteer altijd als 1:1 vierkant, minimum 1000×1000px.

## Selectiecriteria
- Herkenbaar op klein formaat (thumbnail-test op 110px)
- Clean — maximaal 2 visuele elementen
- Hoog contrast — werkt op wit én zwart achtergrond
- Premium uitstraling — geen stock-look, geen generieke AI-aesthetic
- Brand-consistent met de Titan X productlijn
