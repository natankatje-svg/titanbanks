# Dataset Rules

Only include accurate Titan X product references.

Allowed:
- OEM manufacturer photos
- White-background product references
- Sharp front/back/side photos
- Port close-ups
- Cable close-ups
- Strap close-ups
- Display close-ups
- Accurate hand-scale references

Not allowed:
- Failed AI renders
- Wrong port layouts
- Distorted logos
- Competitor products
- Images with fake features
- Low-resolution unusable references
