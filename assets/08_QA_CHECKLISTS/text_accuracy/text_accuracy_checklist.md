# Text Accuracy Checklist

Before approval, check:

- Is all text spelled correctly?
- Is TITANBANKS spelled correctly?
- Are there no distorted letters?
- Are there no random extra words?
- Is the text readable on mobile?
- Is the copy short and premium?
- Is there one clear message?
- Is there no “Buy now”?
- Is there no “More info”?
- Is there no cheap urgency language?
