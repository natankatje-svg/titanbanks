## Composition Patterns to Steal for Titan X

| Pattern | Source ad | Best Titan X application |
|---------|-----------|--------------------------|
| Vertical I-stack | 01 | Story / TikTok 9:16 hero |
| Horizon-line silhouette | 02 | Pure brand teaser, no copy |
| Symmetric flanking | 03 | "One bank, six devices" with device silhouettes flanking |
| Light-streak off-axis | 04 | Meta feed 4:5 / 1:1 hero |
| Landscape split + low-op context | 05 | Web banner / display |
| In-environment + edge cues | 06 | Festival night / coffee shop / road trip context shots |

## Patterns to Reject

- Cyan/blue palette (entire set) → swap to single warm orange accent
- "% Rabatt" / "% Off" CTA pills → swap to "Join the Waitlist"
- Search-bar brand lockup → quiet TITANBANKS wordmark only
- "NEU" green badge → "Coming Soon" in matte typography or no badge
- Speech-bubble urgency badges → never reuse
- Multi-stat overlays (3+ stats per frame) → max 2, ideally 1
