# Competitor Ads Usage Rules

Use competitor ads only for:
- Structure
- Psychology
- Visual hierarchy
- Hook pattern
- Layout logic
- Scroll-stopping mechanism
- Conversion flow

Do not use competitor ads for:
- TitanBanks brand identity
- Product accuracy
- Copying competitor logos
- Copying proprietary assets
- Copying exact brand styling

For every competitor ad, analyze:
1. Visual hierarchy
2. Layout structure
3. Primary focal point
4. Secondary elements
5. Visual flow
6. Design elements
7. Copy breakdown
8. Psychological angle
9. Why it works
10. What to preserve for Titan X
11. What to adapt for Titan X
