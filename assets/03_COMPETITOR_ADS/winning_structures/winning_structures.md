## Cross-Template Rules

| Rule | Source | Applies to |
|------|--------|------------|
| Single claim per creative | brand voice | All templates |
| Centered or off-axis composition — never busy | swipe set | All |
| Max 2 stats per frame | swipe set | All |
| Display alive at 100% (post hand-edit from 188%) | captions/INDEX | All product shots |
| Carry loop visible whenever possible | brand asset | All |
| Logo spelling exactly TITANBANKS | hard rule | All |
| Never both short ends in same frame | product accuracy | All |
| No people, no body parts, no hands | captions negative constraints | All |
| Warm orange (`#FF6B00`) used as a single accent only | brand colors | All |
| Background `#0A0A0A`–`#1A1A1A` | brand colors | All |
| No "% off," no urgency timers, no date windows | forbidden claims | All |
| No wattage / charging-speed claim | open questions | All |
| No airplane / TSA / carry-on | hard rule | All |
