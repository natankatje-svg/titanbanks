DISPLAY LOCK (read before writing any prompt)
---------------------------------------------
The TitanX display is a FIXED INDUSTRIAL UI ELEMENT. It must NOT be re-generated,
re-interpreted, or redesigned. Treat it as a physical component with a locked appearance.

Exact display anatomy (copy from reference — do not invent):
  PANEL     : recessed rectangular dark/black panel in upper front face
  DIGIT FONT: dot-matrix pixel grid — small individual lit pixels forming digits
              NOT 7-segment, NOT LCD, NOT smooth vector font, NOT handwriting
  VALUE     : a valid battery percentage — integer between 1 and 100, maximum two digits
              followed by the % symbol. NEVER above 100. NEVER "188%", "199%", "999%"
  LAYOUT    : [digit(s)][%] left-to-right — do NOT rearrange or stack
  ICON      : one small green charging lightning bolt symbol, positioned to the RIGHT
              of the % symbol — same size, same color, same position as reference
  BACKGROUND: dark panel behind all digits — digits appear as lit white/grey pixels
  GLOW      : subtle diffuse glow around the lit pixel area — not a spotlight
  SPACING   : compact, same character spacing as reference — digits do not float apart

Anti-hallucination rules (enforced, non-negotiable):
  ✗ No value above 100
  ✗ No three-digit numbers that exceed 100 (e.g. 188, 199, 256)
  ✗ No smooth sans-serif or serif digit fonts
  ✗ No rearranged icon position (icon is always to the right of %, never above or below)
  ✗ No added lines, no secondary readout, no extra symbols
  ✗ No redesigned panel shape or size
  ✗ No LCD-style segment digits
  ✗ No blinking or motion artifact interpretation
